The Dorka CLI is the `dorka` command-line interface for scripting a running Dorka editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control Dorka-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → Dorka CLI](/docs/settings). On Linux the command is `dorka-ide`, because GNOME Dorka's screen reader already owns `/usr/bin/dorka` — see [Install → Linux](/docs/install#linux).

Agents can install the matching Dorka CLI skill with:

```bash
npx skills add https://github.com/stablyai/orca --skill dorka-cli
# headless / no Settings UI:
dorka skills install --skill dorka-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable Dorka skill, including `dorka skills install` / `dorka skills update`.

## Install & verify

```
command -v dorka
dorka status --json
```

## Worktree commands

```
dorka worktree ps --json
dorka worktree create --repo id:<repoId> --name my-task --issue 123 --json
dorka worktree current --json
dorka worktree set --worktree active --comment "reproduced bug" --json
dorka worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [Dorka CLI reference](/docs/cli/reference).

## Terminal commands

```
dorka terminal list --json
dorka terminal read --json
dorka terminal send --text "continue" --enter --json
dorka terminal wait --for tui-idle --timeout-ms 30000 --json
dorka terminal create --worktree path:/projects/app --command "npm test" --json
dorka terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs in the active Dorka worktree from a shell:

```
dorka file open src/App.tsx
dorka file diff src/App.tsx --staged
dorka file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `dorka tab profile`; start with `dorka tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `dorka automations` to create, inspect, run, and remove scheduled Dorka tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in Dorka account (`dorka artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
dorka goto --url https://example.com --json
dorka snapshot --json     # returns refs like @e1, @e3
dorka click --element @e3 --json
dorka fill --element @e1 --value "user@example.com" --json
dorka screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
dorka set device --name "iPhone 12" --json
dorka screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through Dorka's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator from `dorka emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving Dorka.

```
dorka emulator list --json
dorka emulator attach "<device-name-or-udid>" --json
dorka emulator tap 0.5 0.7 --json
dorka emulator type "hello" --json
dorka emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
dorka emulator rotate landscape_left --json
dorka emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
